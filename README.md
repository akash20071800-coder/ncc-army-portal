# NCC Army Wing Portal Starter

This repository contains a working starter portal for the NCC Army Wing Anna University concept.

Features included:
- Login screen with Admin / 3rd Year / 2nd Year / ANO
- Dashboard
- Create NR flow
- Letters module
- Records module
- Attendance module
- Volunteer work module
- Finance module
- Drive module
- Cadets module
- Admin settings page with editable values
- Data saved in browser localStorage

How to use:
1. Open `index.html` in a browser, or serve with any static host.
2. Login with the default demo admin user:
   - User: Admin
   - Password: admin123
3. Update the portal details from the Admin panel.
4. Replace the demo data with real college names, cadets, ANOs, and templates after you finalize them.

Notes:
- This is a starter app and not yet a production backend.
- The project is designed to be extended into a full web app with real database + authentication later.
- Admin can edit portal metadata, colleges, and settings from the UI.

Next planned expansion:
- React or Vue frontend
- PostgreSQL / Supabase backend
- Real authentication
- Excel and Word export
- Cloud hosting and shared data
- Admin no-code configuration panels for all modules

This starter app matches your requirement: "Admin can edit" and the rest of the details can be updated afterward.
